# Меню внутри сообщения

Пользовательские экраны `MainMenu`, `Subscription`, `Gifts` и `Whitelist` поддерживают Rich Messages Telegram Bot API 10.3. Информация и кнопки находятся внутри одного сообщения; баннер сохраняется в начале сообщения.

На главной информация и действия собраны по блокам: доступ VPN, белые списки, подарок, приглашения и поддержка, кабинет и дополнительные кнопки. Профиль раскрывается отдельно. Кнопки создаются из уже отфильтрованной клавиатуры: callback-данные, ссылки, Mini App, копирование, выбор чата, условия доступности и права сотрудников сохраняются. Обработчики покупок, оплаты, подарков и подключений не меняются.

`BOT_USE_RICH_MESSAGES=true` включает новый вывод. Значение по умолчанию — `true`. Для возврата к обычному оформлению установите `BOT_USE_RICH_MESSAGES=false` и перезапустите бот. Миграции базы и обновление зависимостей не нужны.

Для проверки владельцем перед общим выпуском используйте `BOT_RICH_MESSAGES_OWNER_ONLY=true`. Остальные пользователи продолжат видеть обычное меню. После проверки установите `false` и перезапустите бот.

Если API отклоняет новый формат, бот отправляет исходное сообщение с полной клавиатурой и баннером. Неподдерживаемый тип кнопки или медиа также сохраняет обычное оформление. При сетевой ошибке дополнительное сообщение не отправляется, поскольку результат первого запроса может быть неизвестен.

Нативное оформление определяет Telegram: точные цвета и размеры зависят от клиента и темы. Браузерный макет не подтверждает отображение в Telegram.

## Проверки

Полный набор `pytest` проверяет текущую бизнес-логику. Дополнительные проверки покрывают сохранение данных кнопок, экранирование, баннеры, редактирование одного сообщения, отключение старых встроенных кнопок и возврат к обычному оформлению. Сценарии подарков и покупки белых списков проходят через настоящий диспетчер с имитацией Telegram API в обоих форматах.

Для тестов базы подарков нужен отдельный PostgreSQL по адресу, разрешённому фикстурой `tests/test_gifts.py`. Рабочая база не используется.

После выпуска требуется проверка на актуальных клиентах Telegram: главное меню, подключение и резерв, устройство, продление, промокод, подарок и его история, белые списки, приглашения, кабинет, поддержка и дополнительные кнопки. Локальные тесты не подтверждают реальную оплату или внешний VPN-трафик.
